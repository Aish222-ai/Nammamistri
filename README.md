# NammaMistri 🏗️

NammaMistri is an Android application developed to calculate basic construction materials required for building work. The app helps users estimate the number of bricks, quantity of cement, and sand required based on the dimensions entered by the user.

## 📱 Features

- Calculate required construction materials
- User-friendly interface
- Input dimensions such as:
  - Length
  - Width
  - Height
- Displays:
  - Number of bricks
  - Cement quantity
  - Sand quantity
- Simple and efficient design

## 🛠️ Technologies Used

- Kotlin
- XML
- Android Studio

## 📂 Project Structure

- `MainActivity.kt` – Main screen and navigation
- `CalculatorActivity.kt` – Material calculation logic
- `activity_calculator.xml` – UI design for calculator page
